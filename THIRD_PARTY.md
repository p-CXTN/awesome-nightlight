# Third-party components

The MIT license covers this project's original source, documentation, and hardware design files. It does not relicense external dependencies or firmware components supplied by Espressif.

The supplied binaries use [Arduino-ESP32 3.3.6](https://github.com/espressif/arduino-esp32/tree/3.3.6) (LGPL 2.1) and [ESP-IDF 5.5.2](https://github.com/espressif/esp-idf/tree/v5.5.2) (Apache 2.0 plus component-specific licenses). Copies of the main licenses are in `licenses/`; retain upstream component notices when redistributing their code. The complete project source and build instructions are included to rebuild firmware with modified libraries.

Development tools (Arduino CLI, esptool, pyserial, Playwright, Pillow, NumPy, SciPy, Shapely) retain their respective licenses and are installed separately.
